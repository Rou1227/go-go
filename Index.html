🤖 真實 AI 串接說明

目前原型使用模擬 AI（依任務分類給合理回饋）。正式上線時請替換成真實 Vision 模型。

建議串接方式（擇一）：

1. OpenAI GPT-4o / GPT-4.1 Vision
在 runAICheck() 內把圖片轉 base64 後呼叫：
POST https://api.openai.com/v1/chat/completions
提示詞範例：「你是超商稽核員。請判斷這張照片是否符合任務要求：『{任務名稱}』。只回傳 JSON：{"pass":true/false,"reason":"簡短中文說明"}」

2. Google Cloud Vision / Gemini
使用 Gemini 1.5 Flash 或 Vision API 做類似判斷。

3. xAI Grok Vision（若有 API）
同樣以多模態對話方式傳圖 + 提示詞。

安全提醒： API Key 請放後端，不要寫在前端。正式環境建議用 Firebase / Supabase Edge Functions 或自有後端代理。

目前程式碼中 runAICheck() 與 generateMockAIResult() 可直接替換成真實 API 呼叫。
